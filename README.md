# MeloGlass V29

- Library header and Songs / Artists / Albums selector remain visible while the song list scrolls.
- Lyrics are overlaid in a compact transparent rectangle centered on album artwork, limited to two lines.
- Next/Previous and automatic next use the exact queue that the song was started from.
- Songs view uses sorted Library order; Artists and Albums use their visible group order; Favorites uses Favorites order.
- Existing long-press artwork menu and local audio + matching LRC import are retained.
