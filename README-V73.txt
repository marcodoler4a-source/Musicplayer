Musix V73 - development source

Added: Files-accessible backup folder export/restore, SHA-256 duplicate scan, full-screen synced karaoke with tap-to-seek, expanded mini-player preference, extra listening statistics. Retains V72 playlists, manual Up Next queue, and Stop After Current.

Not complete: actual audio-reactive visualizer, gapless engine transition and crossfade, and wiring the expanded mini-player preference into the existing mini-player presentation. Do not treat this as an 11-feature complete release.

The backup is a directory in On My iPhone > Musix > MusixBackup. Copy the entire directory to another location before deleting the app. Restore by copying it back.

No iOS/Xcode build validation performed in this environment.
